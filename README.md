## 💡 Troubleshooting

Most issues arise from file restrictions or system settings.

**The software says the file is locked.**
Close the PDF file if you have it open in a viewer or an editor. The software cannot write to a file that is currently in use by another program.

**The output file looks different from the original.**
Ensure your original PDF is not a scanned image. This tool works best on text-based PDFs. If your PDF is a picture of text, use software with optical character recognition first.

**The software stops during conversion.**
Check your internet connection if the tool requires remote processing. If the conversion happens locally on your machine, check if your computer has enough free memory. Close other programs if your computer feels slow.

**Can I undo a conversion?**
The tool creates a new file rather than overwriting your original. Keep your original document in a separate folder until you confirm the new file meets your needs.
